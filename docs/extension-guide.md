# IRIS 크롬 확장 프로그램 설치·사용 방법

쇼핑몰(나이키·아디다스 등) 상품 상세페이지에서 버튼 한 번으로 그 옷을 웹캠 속 내 몸에 입혀 봅니다.
카메라 영상은 이 컴퓨터 안에서만 처리되며 어디에도 전송·저장되지 않습니다.

지원 브라우저: Chrome, 네이버 웨일, Microsoft Edge(모두 크롬 확장 프로그램 사용 가능)

## 1. 내려받기

- 사이트가 열려 있으면: https://rudals906377.github.io/IRIS/iris-extension.zip
- 또는 저장소의 [release/iris-extension.zip](../release/iris-extension.zip) → 오른쪽 위 **Download raw file**

내려받은 zip 파일을 **더블클릭해 압축을 풉니다.** `iris-extension` 폴더가 생깁니다. 이 폴더는 지우지 말고 그대로 두세요(크롬이 이 폴더에서 확장 프로그램을 읽습니다).

## 2. 크롬에 설치(처음 한 번)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다** 클릭 → 1에서 푼 `iris-extension` 폴더 선택
4. 주소창 오른쪽 퍼즐 모양(확장 프로그램) 아이콘 → **IRIS 가상 착용** 옆 핀을 눌러 툴바에 고정

설치할 때 "모든 웹사이트의 데이터 읽기·변경" 권한 안내가 나옵니다. 여러 쇼핑몰의 상품 사진을 받아오기 위한 것이며, 확장 프로그램은 사진만 읽고 페이지를 바꾸지 않습니다.

웨일: `whale://extensions`, 엣지: `edge://extensions` 에서 같은 방법으로 설치합니다.

## 3. 사용하기

**방법 A — 툴바 버튼**
1. 나이키·아디다스의 상의 상세페이지를 엽니다.
2. 툴바의 IRIS 아이콘(주황 고리)을 누릅니다.
3. 새 창이 열리고 카메라 권한을 물으면 **허용**합니다(처음 한 번).
4. 아래 목록의 **페이지 사진 1, 2, …** 중 옷만 찍힌 사진(모델 착용 사진 말고)을 고르면 자동 분석 후 바로 입혀집니다.

**방법 B — 사진 우클릭**
1. 상세페이지에서 입어 보고 싶은 상품 사진을 **마우스 오른쪽 버튼**으로 클릭
2. **IRIS로 이 옷 입어보기** 선택

## 4. 잘 나오게 하려면

- 밝은 곳에서, 상반신(양 어깨)이 화면에 들어오게 서 주세요.
- 몸에 맞는 밝은 무지 반팔을 입으면 가장 자연스럽습니다(원래 옷의 주름을 새 옷에 옮깁니다).
- 옷이 크거나 작으면 창 오른쪽 위 **설정 → 옷 맞춤**에서 어깨 폭·높이·기장을 조절하세요.
- 상품 사진은 배경이 단색인 **옷만 찍힌 사진**이 가장 잘 됩니다. 모델이 입은 사진은 아직 지원하지 않습니다.

## 5. 지금 버전의 한계

- 상의(반팔·긴팔·맨투맨·후드 등)만 자동 분석합니다. 하의·모자·장갑은 개발 중입니다.
- 뒤돌기(옆으로 60° 이상)는 상품 사진에 뒷면 정보가 없어 옷이 서서히 사라집니다.
- 흰 배경 위의 흰 옷, 보디수트, 민소매 일부는 자동 분석이 실패할 수 있습니다(실패하면 안내 문구가 나옵니다).

## 6. 업데이트하기

새 zip을 받아 같은 폴더에 덮어쓴 뒤 `chrome://extensions` 에서 IRIS 카드의 새로고침(↻) 버튼을 누릅니다.
