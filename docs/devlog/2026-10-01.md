# 2026-10-01 개발일지

## 생성 모드(사진 한 장): 약한 부분을 생성형 AI로

사용자 요청 "약한 것 수정, 생성형 AI 사용". 실시간으로는 안 되는 헤어 모양·길이, 세밀한 네일아트, 사진 그대로의 타투를 생성형 AI로 그리는 모드를 만듦.

### 한 일
| 항목 | 내용 |
|---|---|
| 생성 서버(파이썬) | FastAPI. MediaPipe로 다시 그릴 영역(머리카락+주변, 손톱, 팔·목·쇄골) 마스크 → Stable Diffusion 1.5 인페인팅 + IP-Adapter(참고 사진 따라 그리기). 마스크 안만 새로 그리고 얼굴·배경은 원본 유지. `--dry-run`으로 모델 없이 연결 시험 |
| 웹 | ✨ 생성 버튼 → 지금 모습 한 장 + 참고 사진 + 스타일 AI 속성(영어 설명) 전송 → 전후 비교 슬라이더·저장. 설정에 서버 주소 |
| 시험 | 클라우드(CPU)에서 시험 모드로 헤어·네일·타투 마스크 확인, 웹 → 서버 → 결과 표시까지 자동 시험 통과. 실제 모델 CPU 생성은 작은 크기로 진행 |
| 버그 | 탭을 다시 그릴 때 📷·✨ 버튼이 사라지던 문제 수정 |

### 문제와 해결
- 클라우드에 그래픽 라이브러리(libEGL)가 없어 MediaPipe(파이썬)가 안 돌음 → 시스템 라이브러리 설치
- 분할 마스크가 (높이, 너비, 1) 모양이라 오류 → squeeze
- 서버를 끄는 명령이 자기 자신까지 꺼 버림 → pid 파일 방식

### 결정 사항
- 생성은 사용자 컴퓨터(GPU)에서 로컬로. 사진이 인터넷으로 나가지 않고 비용이 없음
- 헤어는 "같은 사람"을 지키기 위해 얼굴 피부를 마스크에서 빼고 머리 주변만 다시 그림

### 실제 모델 CPU 시험(작은 크기 384px, 12~16단계)
- 헤어: 금발 참고 사진 → 시험 얼굴이 금발로, 얼굴·귀걸이·옷 유지(51초). 모양 변화는 작음(크기·단계가 작아서)
- 네일·타투: 전체 화면에서 그리면 부위가 너무 작아 거의 안 바뀜 → 마스크 주변만 잘라 크게 그리도록 수정. 분야별 세기 기본값(네일 0.65, 타투 0.45)으로 실시간 합성 결과를 살리며 녹이는 방식. CPU 작은 크기에서는 변화가 미미해 GPU 실사용 확인 필요
