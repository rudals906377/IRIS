## 사진 모드 자동 개선 반복(밤새 ~ 오후) → 얼굴 무너짐에 전용 모델 → 제품 정의 다시 확인

어제부터 이어진 "사진 모드 품질 자율 개선 한 바퀴"(결함 고르기 → 확대 비교 → 원인 수치 → 고치기 → 회귀 → 테스트 → 커밋·문서 → 전후 그림 + 요약)를 밤새 돌렸다.
낮에 사용자가 "얼굴 무너지고 변형되는 것 최대한 잡아 달라, 필요한 모델은 찾아 써도 된다"고 해 얼굴 바꾸기에 전용 모델을 붙였고,
곧이어 **"얼굴 두 개를 합성하는 게 아니다. 메이크업·헤어·네일·타투만 따와서 적용하는 것. 인식 못 하면 못 했다고 해 달라"**고 제품 정의를 분명히 해 주어 그대로 정리했다.

### 얼굴 바꾸기 전용 모델(낮)
- 사진처럼 그리기 서버(8767)에 `/swap` 추가: InsightFace buffalo_l(얼굴 찾기·정렬·임베딩) + inswapper_128 이 고른 사진 얼굴 자리에 내 얼굴을 다시 그리고, GFPGAN v1.4(ONNX)로 512 정렬 복원(기본 75% 섞음) 뒤 되돌려 붙임. CPU 로도 한 장 3~8초.
- 생성 서버(8765) `/swap`: 결과에서 고른 사진 **얼굴 피부 자리만** 섞고, 얼굴 위를 지나는 가는 머리카락 가닥(눈 둘레 제외)은 원본을 둠(모델이 128 해상도로 다시 그려 가닥이 톱니처럼 끊겼고, 눈을 안 빼면 고른 사진 속눈썹이 내 눈 위에 겹쳤음).
- 웹: 서버 모델이 켜져 있으면 먼저 그쪽, 없거나 실패하면 브라우저 점 휘기. 점 휘기에서 코·입이 무너지던 세 쌍 모두 얼굴 모양이 온전함.

### 문제와 해결
- 효과 없거나 악화된 시도는 되돌림: 머리 속 '가닥 없는 새까만 픽셀 버리기'(머리 속 네모 구멍), 얼굴 바꾸기 넓은 틈 메우기(1px 차이), 안경 능선 밝기 기준(코받침 조각 242 → 435 악화), 눈가 어두운 올 비율 지표(모든 사진 13~19% 로 구별 안 됨), 흑발 밀랍 결(원본 윤기 덩어리가 원인, 올 방향 실험 효과 없음).
- inswapper 첫 결과가 거칠어 보인 것은 얼굴 상자 전체를 128 로 다시 그려 앞머리까지 뭉갠 탓 → 얼굴 피부만 섞고 가닥은 원본 유지로 해결. 서버가 "켤 모델이 없다"며 꺼진 것은 가중치 파일이 지정 폴더 밖에 있어서.
- 컨테이너 재시작으로 미리보기 서버가 죽거나, 디버그 훅을 지운 뒤 덤프가 빈 채로 끝나는 일이 몇 번 → 서버 재시작·훅 다시 넣고 재실행. `pkill -f` 가 내 셸까지 죽여 시작 스크립트 파일로 바꿈.

### 결정 사항
- **제품 정의(사용자)**: 얼굴 두 장 합성이 아니라 고른 사진의 메이크업·헤어·네일·타투만 내게 옮긴다. 🔁 사진 속에 내 얼굴은 `?swap=1` 일 때만 보이는 시험 도구로 숨기고(코드·서버 모델은 남김), 앞으로의 개선 바퀴는 네 분야 품질에만 쓴다.
- 고른 사진에서 못 찾은 분야는 사진 아래에 "…은 이 사진에서 찾지 못했어요"라고 알린다(넷 다 못 찾으면 또렷하게 크게 보이는 사진을 고르라는 안내).
- inswapper 가중치는 비상업·연구용, GFPGAN 은 Apache-2.0(일부 구성 요소 별도) → README 에 명시.
