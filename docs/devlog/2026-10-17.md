## 사진 모드 자동 개선 반복(밤새 ~ 저녁): 자연스럽고 부드러운 결과

사용자 요청: "사진 모드 품질 자율 개선 한 바퀴: 가장 약한 부분이나 눈에 띄는 결함을 골라 여러 쌍 확대 비교 → 원인 수치 확인 → 고치기 → 회귀 확인 → 테스트 → 올리기 → 전후 그림 + 짧은 요약. 자연스럽고 부드러운 결과 우선", "바로바로 진행해".
어제 저녁부터 이어진 자동 반복을 오늘 하루 계속했다. 한 바퀴마다 시험 사진 조합을 새로 굽거나 확대해 가장 눈에 띄는 결함 하나를 고르고, 브라우저 밖 재현(덤프 + Node)으로 원인 수치를 찾은 뒤 고쳤다. 실제 사진에서 효과가 없던 시도는 되돌렸다.

### 문제와 해결
- 효과 없는 시도는 되돌림(커밋 2개 + 커밋 전 되돌림 다수): 금발을 어둡게 할 때 가장자리 알파를 색으로 다시 재기(햇빛 받은 끝머리가 배경과 섞여 0.66 까지만, 턱 쪽 피부에 머리색이 묻음), 긴 네일 뿌리 크롬 붙이기(끝 너머 그림자가 붙음), 헤어 가장자리 순위 상한, 잔머리 색 선 검사, 짧은 머리 흰 소용돌이(질감 요소를 꺼도 수치 그대로), 사진 둘레 회색 선(원본 사진에 이미 있는 테두리), 하이라이트 순위 모으기, 팔 피부 캡슐 제한, 어긋난 손 점 무시한 손톱 더 찾기
- 반바지 사진에 고른 '허벅지' 타투가 아래팔에 놓인 것은 결함이 아니었음: 고른 사진이 팔인지 다리인지 모를 가까운 사진이라 AI 자리 확신이 0.32(어깨 0.26·팔안쪽 0.18)로 기준 미달 → 기본 자리(아래팔)
- 시험 도구 함정: 3개를 동시에 굽는 사이 25초 만에 찍어 "안 바뀐 것"처럼 보임(실제는 굽기 전) → 굽기를 충분히 기다림. 큰 사진(1500×2000) 2개 동시 굽기는 브라우저가 죽음 → 하나씩
- 얼굴 바꾸기 Lab 변환 첫 시도가 새까만 얼굴: 표 찾기 함수에 소수 색값을 넣음 → 반올림
- 네일 단계별 탈락 이유·헤어 알파 단계별 값·메이크업 픽셀 탐침을 잠시 넣어(DEBUG-DUMP 표시) 원인 단계를 정확히 찾고, 끝나면 지움
- 한 번 결과 사진 전체가 검게 찍힘(재현 4번 실패) → 기록만

### 결정 사항
- '검은 배경 위 검은 머리' 알파 번짐은 분할 모델 셋 모두 머리카락·사람으로 봐 가를 근거가 없음 → 보류. 대신 흑발로 바꿀 때 회색이 되지 않게 해 번짐이 티 나지 않게
- 피부색이 다른 얼굴 바꾸기는 고른 사진 피부 톤에 맞추되(목·귀와 이어지게) 대비는 빛 세기 비만큼만
