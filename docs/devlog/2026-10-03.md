### 문제와 해결
- `huggingface.co/xichenhku/AnyDoor` 는 401(비공개) → 공개 축약본 `bdsqlsz/AnyDoor-Pruned`(4.9GB) 사용. 윈도우 포팅이 쓰는 DINOv2 reg4 가중치는 공식 설정(vitg14, 레지스터 없음)과 다를 수 있어 공식 파일 사용
- AnyDoor 는 참고 물체를 대상 상자 크기로 **늘려** 넣으므로 가로세로 비율이 다르면 찌그러짐 → 타투 자리는 참고 물체와 같은 비율의 상자로
- 네일 근접 사진은 손 점이 안 잡힘 → 가운데 45% 상자를 물체로
- 환경 충돌: AnyDoor 는 torch 2.0·transformers 4.19·pytorch-lightning 1.5 에 묶여 있어 생성 서버 venv(torch 2.14, transformers 5)와 공존 불가 → 전용 venv + 별도 포트(8766)

### 결정 사항
- 실시간 화면은 "미리보기", AnyDoor 는 "고품질 한 장". 보고서는 기본 엔진(SDXL+IP-Adapter) vs AnyDoor 비교 실험으로
- 순서: 타투(가장 잘 맞음) → 네일 → 헤어
