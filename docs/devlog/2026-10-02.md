## 문제와 해결

- 머리 잘라 분할 합치기에서 영상 크기 대신 합친 폭을 써서 좌표가 2.5배 틀어짐(머리카락이 턱·옷에 칠해짐) → 영상 크기를 넘겨 수정
- 올 가려내기 띠가 확률 0.04부터 시작해 벽 무늬를 올로 오인(빨간 점) → 0.15부터, 더하기 방식
- 사용자 스크린샷을 시험 영상으로 쓰니 효과가 이미 입혀져 있어 색은 판단 불가 → 위치 확인용으로만, 공개 시험 영상으로 색 검증
- 학교 PC에서 .bat 더블클릭이 안 됨(정책) → 명령 프롬프트 직접 입력 안내. 배치 파일은 CP949·CRLF로 변환
- 터널 주소를 Ctrl+C로 복사하다 터널이 종료됨 → 드래그 후 Enter로 복사 안내
- SD1.5 생성이 노랑을 연두·투톤으로 그림(시드별로 2/3 실패) → 색 고정 후처리로 해결(회색·보라도 노랑으로 복귀)
- transformers 5 + diffusers 0.40에서 attention slicing이 IP-Adapter 어텐션 처리기를 덮어씀 → 끔
- 2차식 피부 흐름이 머리카락으로 반쯤 덮인 얼굴에서 예상 피부색을 0 근처로 외삽(비율 235배) → 정칙화·범위 제한
- ONNX 내보내기가 가중치를 .data로 분리해 브라우저가 못 읽음 → external_data=False
- 클라우드 작업 환경 사용량 한도로 조사 워크플로 2개 실패 → 이미 모인 1차 출처로 결론, 나머지 생략

## 결정 사항

- 사용자 우선순위: 사진 따라하기 > 모든 것. 기본 룩은 맨 뒤
- 생성 모드는 (a) 내 컴퓨터 GPU 서버로 확정. Decart API는 비용·외부 전송 때문에 보류
- "자체 모델"은 바닥부터 학습이 아니라 **문제 맞춤 소형 모델**로: ① 머리카락 매팅 ② 손톱 분할 ③ 헤어 생성 LoRA. ①→②→③
- 실시간 생성 영상(JoyAI·Decart급)은 무료·3080 조건에서 불가. 5090 대여 하루 실험만 선택지로 남김
- 사용자가 라벨 작업에 참여하기로 함(손톱). 머리카락은 자동 라벨
