3. **배포·시험 체계:** GitHub Pages 자동 배포, 단위 테스트, 헤드리스 브라우저 시험 도구(가짜 웹캠으로 착용 결과 캡처).
4. **상품 사진 자동 분석:** 아무 쇼핑몰 사진에서 배경을 지우고 목·어깨·겨드랑이·소매·밑단 위치와 부위를 찾아 바로 입힘.
5. **크롬 확장 프로그램:** 쇼핑몰 상세페이지에서 아이콘 한 번으로 상품 사진을 모아 착용 창을 연다.
6. **분석 정확도 개선:** 시험 사진 21장 중 신뢰도 0.6 이상 9장 → 16장.
7. **모델 착용 사진 지원:** 옷만 찍힌 사진이 없을 때 모델 사진에서 상의만 잘라 입힘.
8. **실제 나이키 상세페이지 시험:** 네트워크 허용 후 상의 14개 조사, 확장 프로그램 전체 흐름 성공.

## 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 흰 티셔츠가 흰 배경과 함께 지워짐 | 배경색 허용 범위가 넓어 옷 안으로 번짐 | 배경이 균일하면 범위를 좁히고, 지나온 배경색을 따라가며 작은 밝기 계단에서 멈추게 함 |
| 소매를 몸 옆에 늘어뜨린 옷의 겨드랑이가 너무 낮게 잡힘 | 소매와 몸판 사이 틈이 아래쪽에만 보임 | 윤곽의 볼록 껍질 틈(오목한 골)을 분석, 좁은 틈이면 옷 비율로 겨드랑이 높이 추정 |
| 후드 모자를 목으로 착각 | 모자가 어깨선보다 높이 솟음 | 모자와 어깨가 만나는 골을 목둘레로, 모자는 목 뒤 부위로 |
| 추천 상품(다른 옷) 사진이 선택됨 | 페이지의 큰 이미지를 모두 모음 | 다른 상품으로 가는 링크 안·페이지 한참 아래 사진 제외 |
| 나이키에 옷만 찍힌 사진이 없음 | 실측 결과 상의 갤러리가 모두 모델 사진 | 모델 착용 사진 분석을 기본 경로로, 정면 상반신이 나올 때까지 후보를 차례로 시도 |
| 모델 사진에서 바지까지 잘려 들어옴 | 분할 모델이 상의·하의를 모두 '옷'으로 봄 | 엉덩이 근처에서 색이 크게 바뀌는 줄을 밑단으로 |
| 반팔 안에 겹쳐 입은 긴팔이 소매로 들어옴 | 겹쳐 입은 옷도 '옷'으로 분할 | 팔을 따라가며 색조가 바뀌고 몸통 색과도 다른 곳에서 소매를 끊음(그림자는 밝기만 바뀌므로 구분) |
| 두 사람이 나온 연출 사진 | 어느 옷인지 알 수 없음 | 사람이 둘 이상이면 그 사진은 건너뜀 |
| 아디다스 접속 403 | 클라우드 서버 주소의 자동 접속을 사이트 보안이 차단 | 우회하지 않음. 사진 주소 규칙만 확인, 상세페이지는 맥북 크롬에서 확인 예정 |

## 결정 사항

- **AnyDoor는 쓰지 않는다**(교수님: 더 좋은 모델·방식을 찾으면 써도 됨). 실시간이 가능한 IRIS 자체 방식(브라우저 안 추적 + 마스크 합성)을 중심으로 빠르게 완성하고, 남은 기간은 완성도를 끌어올린다.
- 고화질 사진 한 장 모드가 필요해지면 옷 전용 모델(CatVTON, IDM-VTON 등)을 사용자 NVIDIA PC에서 돌리는 방안을 검토한다.
- 공개 저장소이므로 나이키·아디다스 사진 파일은 커밋하지 않는다(시험용 사진은 `web/public/testdata/`, 저장소 제외).

- Claude Code(클라우드 세션)로 조사·설계·구현·시험·문서화를 진행. 사람은 방향 결정과 환경 설정(네트워크 허용)을 맡음.
