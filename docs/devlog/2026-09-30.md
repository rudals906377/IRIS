## 결정 사항

- **AnyDoor는 쓰지 않는다**(교수님: 더 좋은 모델·방식을 찾으면 써도 됨). 실시간이 가능한 IRIS 자체 방식(브라우저 안 추적 + 마스크 합성)을 중심으로 빠르게 완성하고, 남은 기간은 완성도를 끌어올린다.
- 고화질 사진 한 장 모드가 필요해지면 옷 전용 모델(CatVTON, IDM-VTON 등)을 사용자 NVIDIA PC에서 돌리는 방안을 검토한다.
- 공개 저장소이므로 나이키·아디다스 사진 파일은 커밋하지 않는다(시험용 사진은 `web/public/testdata/`, 저장소 제외).

| 피드백 | 한 일 |
|---|---|
| 몸에 달라붙지 않음 | 몸통을 타원 기둥으로 보고, 매 줄 옆선을 분할에서 잰 **지금 입은 옷의 가장자리**에 맞춤(사용자 제안: 몸 대신 입은 옷에 맞추기). 소매는 팔 두께를 재서 관(튜브) 좌표로 팔을 따라 감쌈 |
| 몸을 돌리면 사라짐·작아짐 | 어깨 폭 줄어듦으로 회전 각도를 재어 먼 쪽을 압축하고 옆·뒷면(원단 바탕색)을 보여 줌. 돌아선 상태에서도 옷 크기는 정면 기준으로 유지 |

| 목이 가려짐 | 어깨선 위 피부는 덮지 않음. 목폴라·하이넥·지퍼 올린 져지는 깃 높이로 판정해 목을 덮게 함 |
| 실제 아디다스 트랙탑 캡처(돌아선 자세, 흰색으로 크게 지워짐, 소매 톱니) | 크기 보정, 지우기 범위 제한, 소매 폭 보간·길이 제한 |

### 문제와 해결
- 소매를 네 꼭짓점 사각형으로 보던 방식은 늘어뜨린 소매·모델 사진에서 찌그러짐 → 관 좌표 + 바깥선(어깨점)·안쪽선(겨드랑이) 방식으로 교체
- 접어 찍은 소매의 어깨 쪽 픽셀이 소매 뿌리에 뭉쳐 어깨가 비던 문제 → 뿌리 위쪽도 팔 위로 이어서 배치
- 셰이더에서 선언하지 않은 값을 써 옷이 전혀 안 그려지던 오류 → 수정(배포 전 발견)

### 시험 자료
- 몸 전체를 돌리는 무료 영상(Mixkit), 다른 쇼핑몰 9곳 상의 54개(저장소 제외)

### 문제와 해결

- 예시 인물 영상은 얼굴이 작아(폭 약 90px) 품질 판단이 어려움 → 얼굴 확대 시험 영상을 만듦

## 밤: 헤어 컬러 · 타투 · 네일아트(1차)

| 기능 | 결과 |
|---|---|
| 헤어 컬러 | 머리카락 평균 밝기 대비 각 올의 명암을 살려 염색. 블론드·핑크·옴브레가 자연스러움. 경계 번쩍임과 원색의 평평함을 고침 |
| 타투 | 팔은 원기둥으로 감고 피부에만 새김. 아래팔 들꽃·레터링이 실제처럼 보임. 목은 얼굴 턱선 기준, 쇄골 아래도 지원 |
| 네일아트 | 1차 완성: 손톱 위치에 색·무늬가 올라가지만 네모나고 위치가 어긋나는 경우가 있어 2차 개선 필요 |

### 문제와 해결
- 시험 영상의 얼굴이 작아 판단이 어려움 → 사진에서 얼굴을 크게 잘라 시험 영상을 만듦
- 달 도안이 안 보임: 두 원호의 반지름이 같아 면적이 0이었음 → 안쪽 원호 반지름을 키움
- 가까운 구도에서 목 타투가 안 나옴: 어깨가 화면 밖이라 자세 추적 실패 → 얼굴 점만으로 목 위치 계산, 가까운 목은 '얼굴 피부'로 분류되는 점도 반영
- 네일이 안 보임: 손등 방향 판단 부호가 반대였음 → 손등이 보이는 시험 영상 두 개로 부호 확인 후 수정. 두 손이 같은 쪽 손으로 판정되면 필터가 겹치던 문제도 고침
- 시험 도구가 얼굴이 없는 손 영상에서 계속 기다림 → 손 시험은 얼굴을 기다리지 않게 수정
