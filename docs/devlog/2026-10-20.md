# 2026-10-20 개발일지

## 새 사진 모음으로 시험 → 한국인 기준으로 → 검은 머리 밝은 염색을 '내 머리에서 색만' 바꾸기

사용자가 따로 모아 둔 사진 모음(AI 저장소 photo-collection 브랜치)을 받아 사진 모드 시험 세트를 넓혔다.
낮에 **"모든 기준은 동양인, 특히 한국인 기준으로"** 라는 요청에 따라 한국인 남녀 내 사진(검은 단발·검은 짧은 머리·밝은 갈색)으로 다시 시험했다.
이어 **"은박처럼 보이는 것 없이 진짜 머리카락처럼, 실제 머리에서 색만 자연스럽게 바뀌고 사진 위에 사진을 덮어쓴 느낌은 없애야 한다"** 는 요청에 맞춰 염색 방식을 바꿨다.
(마지막 두 커밋은 자정을 넘겨 10-21 01시에 올렸지만 같은 작업의 연속이라 오늘 일지에 넣는다.)

### 오늘 한 일
| 분야 | 고친 결함(원인 → 고침) |
|---|---|
| 헤어 | 검은 머리를 밝게 염색하면 은박·플라스틱처럼 번들거림(가는 윤기·잡음이 분위 대응으로 가장 밝은 색 + 올 결 되살리기 → 넓은 명암·중간 띠·잔결로 나눠 중간 띠 절반, 잔결은 부드럽게 누름). 그래도 남던 '덮어쓴 느낌'은 방식 자체를 바꿈: 크게 밝히는 염색은 내 머리의 넓은 명암과 그늘 비를 그대로 두고 밝기 수준과 색만 고른 사진으로, 윤기는 원래 크기만 더함(옴브레·하이라이트 사진 포함) |

| 타투 | 가까이 찍은 컬러 타투 피부 색 거르기, 가게 이름 띠가 붙은 시트 닫기 |

### 문제와 해결
- 효과 없거나 다른 사진을 나쁘게 한 시도는 되돌리고 handoff §6 에 기록: 어두운 덩어리 규칙 변경(등 타투 16번 굵은 검은 선·06번 시트 가게 글씨), 잔머리 색도, 귀 붉은기, **MODNet 인물 매팅으로 한 올씩 따기**(켜고 끈 차이가 눈으로 구별 안 됨, 26MB 내려받기), 검증 못 한 네일 반지 거르기·다리 타투를 팔로 옮기기.
- 새 염색 방식 처음 판은 결 세기가 원본의 2.6배(9.4)로 오히려 구리·은박 같았다 → 검은 머리의 밝은 쪽은 대부분 머리색과 무관한 반사라 곱하지 않고 더하도록, 넓은 명암은 윤기를 한 번 깎고 다시 재도록 고침.
- 하이라이트 판정(고른 사진 밝기 폭)이 베이지·로즈골드 웨이브 사진의 자연 명암까지 하이라이트로 읽어 새 방식이 꺼져 있었다 → 하이라이트여도 새 방식, 가닥은 밝기 수준만 올림. 가닥을 1.8배로 세게 하면 밝은 얼룩이 칠한 듯 떠서 되돌림.
- Playwright 가 한글 경로 파일을 조용히 못 올림 → 사진 모음을 영문 이름 사본으로. 일괄 렌더에서 앞 사진 적용이 남음 → 사진마다 새 페이지.

### 결정 사항
- **시험 기준은 한국인 사진**(사용자). 염색·메이크업 수치는 한국인 남녀 사진으로 먼저 확인한다.
- **염색은 '내 머리에서 색만'**(사용자): 원래 명암·결·그늘을 지키는 것이 고른 사진의 결을 재현하는 것보다 우선. 강한 하이라이트가 원본보다 약해지는 것은 감수.
- 효과를 수치·그림으로 보여 주지 못한 모델은 붙이지 않는다(MODNet).

### AI 도구 활용
- Claude Code: 사진 모음 정리 → 일괄 렌더(남녀 × 7색) → 확대 비교·결 세기 측정 → 브라우저 안 임시 기록으로 조건 값 확인 → 수정 → 이전 커밋 빌드와 나란히 비교 → 단위 테스트 → 커밋·handoff → 전후 그림.
- 공개 모델: MediaPipe 얼굴·손·자세·분할, BiSeNet 얼굴 분할, SlimSAM, 스타일 AI 분류기. MODNet(인물 매팅)은 시험 후 뺌.
