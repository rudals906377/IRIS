# 2026-10-08 개발일지

## 정확성·자연스러움을 점수로 재고 올리기

사용자 요청: "자연스러움과 정확성을 높일 방안" → "사용자가 직접 해야 하는 것 빼고 전부 진행". 먼저 점수 도구를 만들고, 바꿀 때마다 같은 자료로 전후를 쟀다.

| 염색 명암 분포 | 실제 머리는 밝을수록 결의 상대 명암이 작다(밝기 0.6 → 변동 0.2, 0.12 → 0.75). 원래 머리 변동을 목표 색 밝기에 맞게 늘이고 줄이고, 평균 밝기는 되돌림 |

| 자체 머리카락 모델 v3 | 웹캠형 자동 라벨 203장(학습용 사람만, ×5) + CelebA 원 라벨 1,200장, 256 입력, CPU 8회(약 1시간 반). 검증 MAD 8.0% |

### 문제와 해결
- 자체 머리카락 모델이 웹캠에서 얼룩: 브라우저 파이프라인 문제가 아니라(오프라인 결과와 일치) 학습 자료 도메인 차이. 사진형 얼굴 IoU 0.91~0.93, 웹캠형 0.0~0.6
- 헤드리스 크로미움은 H.264(mp4)를 못 틀어 평가 영상을 VP8 webm 으로 변환
- 평가 도중 빌드하면 dist/testdata 가 잠깐 지워져 평가가 멈춤 → README 에 주의
- 뿌리 음영: 실제 사진 32장에서 위쪽(뿌리)이 가운데보다 밝은 경우가 많아(중앙값 1.2배) 넣지 않음

### 결정 사항
- 타투는 "도안 그대로 옮기기(실시간)"가 기본, AnyDoor 는 보고서 비교용
- 염색 명암 계수 0.6(0.45 는 결은 조금 낫지만 색오차가 6.4 로 커짐)
- 고칠 때마다 tools/eval 점수를 남긴다

### AI 도구 활용
- Claude Code: 평가 설계(앱과 독립된 교사 모델로 정답, 사람 단위 분리), 실제 머리 사진 통계에서 명암 법칙 찾기, 셰이더·되먹임 수정 후 점수 비교, 웹캠형 자동 라벨·CPU 재학습
