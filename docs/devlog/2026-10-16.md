# 2026-10-16 개발일지

## 사진 + 사진 합성(웹캠 없이) 모드와 헤어·네일·타투·메이크업 디테일, 사진 속에 내 얼굴

사용자 요청 흐름: "이미지 + 이미지 합성도 하나 만들어 줘" → "디테일 좀 살려 줘(헤어·네일·타투, 메이크업도)" → "몇 점 만점이야?" → "점수 낮은 것부터 올려 줘"
→ 중간에 "내 의도는 내가 정한 사진을 내 얼굴에 합성시키는 거야"(둘 다 하기로) → "타투·헤어·메이크업도 이어서" → "전체적으로 무한 학습" → "최대한 자연스럽고 부드럽게 최고 점수가 나오게".
사진은 한 번만 계산하면 되므로, 실시간 셰이더 대신 무거운 계산(정밀 분할·SAM·분포 대응·삼각형 휘기)으로 결과를 사진에 "굽는" 방식으로 바꿨다.

### 오늘 한 일
| 항목 | 내용 |
|---|---|
| 사진 + 사진 모드 | `?mode=photo`: 내 사진을 '멈춘 카메라'(캔버스 captureStream, 66ms 마다 다시 그림)로 열어 칩·진하기·영역·비교 저장·AI 생성을 웹캠 때와 똑같이. 결과는 `replaceStill` 로 사진을 바꿔 끼운다 |
| 헤어 | 정밀 얼굴 분할(BiSeNet ONNX 26MB, WASM) + 가이디드 필터 알파 → 고른 사진 머리색 **분포를 올마다** 옮김(`still-hair.ts`). 어두운 → 밝은 염색의 검은 얼룩·결 없는 곳 올 무늬, **긴 머리 끝까지**(상자 밖은 사진 전체 머리카락 분할), **투톤·옴브레**(세로 3띠), **하이라이트 가닥**(머리 흐름을 따라 문지른 리본), 검은 점 없애기 |
| 네일 | SAM(SlimSAM)으로 손톱을 오려 고른 사진 **실제 손톱 그림**을 내 손톱 모양(주축·폭 분포)에 옮김(`still-nail.ts`). 고른 사진 손톱은 손가락 끝마다(손 점) → 없으면 색 덩어리. 가까이 찍은 손·흰 네일·배경색 대응, 색만 있으면 가상 손톱 그림 |
| 타투 | **팔 대 팔**(위팔→위팔, 아래팔→아래팔, `still-tattoo.ts`), 몸이 안 나온 팔 사진은 피부 영역 최단 경로로 굽은 팔 중심선, 소매 일부만 잡혀도 팔 전체에서 다시 뽑기, **다리**(허벅지·종아리), **도안 시트**(종이 바탕), 가슴·쇄골(어깨 대응), ✂️·📍 로 고른 자리에 정밀하게 굽기 |
| 메이크업 | 고른 얼굴을 내 얼굴 모양에 휘고 **맨 피부와의 차이(화장)만** 옮김(`still-makeup.ts`): 블러셔 모양·코끝 홍조·립 색과 광·눈가 섀도·**날개 아이라인·아래 속눈썹·주근깨**, 조명·피부색 차이는 안 옮김, 손에 가린 곳은 둘레로 메움 |
| 사진 속에 내 얼굴 | 🔁: 고른 사진(머리·화장·옷·배경·손)은 그대로, 얼굴만 내 얼굴로(`face-swap.ts`: 468점 들로네 삼각형 휘기, 두 사진 모두 피부인 곳만, 피부끼리 조명 맞춤). 내 앞머리·얼굴 가린 손은 옮기지 않음 |
| 자동 개선 반복 | 사용자 "무한 학습"에 맞춰 스스로 한 바퀴씩(가장 낮은 부분 고르기 → 시험 사진 여러 쌍 확대 비교 → 원인 수치 확인 → 고치기 → 회귀 확인 → 올리기) 도는 반복을 켬. 1·2회차는 네일 |

### 문제와 해결
- 사진 모드 멈춤: 굽기 작업의 '작업 중' 약속이 할당 전에 바로 끝나 무한 반복 → 작업 객체를 먼저 만들고 끝날 때 '그 작업이면' 지우는 방식
- 정밀 분할 모델: SegFormer 는 너무 느리고 WebGPU 는 headless 에서 멈춤 → BiSeNet 을 fp16 가중치 ONNX(26MB)로 바꿔 WASM 만. `*.onnx` 가 무시 목록이라 강제로 올리고 예외 줄 추가
- 얼굴 바꾸기 이마 띠: 내 앞머리가 고른 사진 이마에 붙음 → 내 사진도 얼굴 분할(머리카락 둘레 5칸 넓혀 뺌) + 피부끼리만 조명 비율. 굽는 사이 🔁 을 누르면 늦게 끝난 결과가 덮어쓰던 문제는 시작 때 사진·모드와 다르면 버림
- 타투: 팔 관절점이 가까운 팔 사진에서 엉뚱함 → 피부·잉크 영역에서 가장 먼 두 끝 사이 최단 경로(굽은 팔도). 진한 타투가 피부로 안 잡혀 구멍 → 거친 칸으로 닫기. 도안 시트가 팔 전체 소매로 붙던 것, ✂️ 로 고른 하트가 안 보이던 것(실시간 타투가 가는 팔에서 가려짐) → 고른 자리에 정밀하게 굽기
- 메이크업: 넓게 흐린 색 바탕이 볼 전체 블러셔를 삼켜 거의 안 옮겨짐 → 색 바탕을 피부 덜 붉은 쪽(5%) 값으로. 손가락이 입술을 가린 사진의 세로 줄 → 손 점으로 손가락까지 빼고 둘레 화장으로 메움. 주근깨 자리에 머리카락 가닥·콧구멍이 따라옴 → 밝기 곡률(헤시안)로 '둥근 점'만, 콧구멍 둘레 뺌
- 헤어 검은 점: 원본의 새까만 픽셀(정보 없음)이 가장 어두운 분위로 몰림 → 덤프해서 브라우저 밖에서 픽셀별로 추적, 루마 24 아래는 둘레 순위를 서서히 빌리고, 하이라이트 리본은 순위를 위로만(다시 펴면 가장 어두운 쪽이 바뀌어 또 점)
- 네일: SAM 이 손 전체를 잡아 손등이 네일 무늬로 칠해짐 → 손 크기 기준 크기 제한, 세 후보 중 점수 비슷한 것 중 가장 작은 것. 실시간 네일이 정지 사진에서 손톱 옆 피부에 어긋나게 얹힘 → 사진 모드는 굽기만. 손 찾기가 가끔 실패 → 그대로·절반·여백으로 여러 번
- 시험 병렬 실행 시 손 찾기·SAM 이 시간·자원 부족으로 들쭉날쭉 → 네일은 한 쌍씩 차례로 시험

### 결정 사항
- 사진 모드는 실시간 셰이더 대신 '굽기'가 기본(헤어·네일·타투·메이크업). 실시간 효과는 굽기 전 미리보기·실패 시 대체로만
- 얼굴 바꾸기와 '내 사진에 입히기'는 둘 다 제공(🔁 / ↩ 로 전환)
- 등 타투를 등으로 옮기기는 보류: 뒷모습에서 관절점이 왼쪽·오른쪽·크기를 자주 틀림 → 팔 미리 보기 + 안내
- 시험 사진은 `web/public/testdata`(무시 목록)에만 두고 커밋하지 않음
