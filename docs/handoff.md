# 작업 인수인계 (다음 세션용)

작성: 2026-09-30(주제 변경 후 갱신). 새 세션이 IRIS **가상 뷰티**를 이어받아 완성하기 위한 문서다.

## 1. 사용자와 약속된 방식

- **모든 대화·진행 안내·문서·커밋 메시지는 한국어**로 쓴다. 영어는 기술 용어에만 쓴다.
- 사용자는 이 분야를 잘 모르며 "알아서 해 달라"고 했다. 결정은 스스로 내리고, 사용자 손이 꼭 필요한 일(맥북에서 직접 써 보기, 설정 한 번 바꾸기)만 짧고 쉽게 요청한다.
- 목표는 "최고의 결과물". 빨리 완성하고 남은 두 달은 완성도를 끌어올린다. AnyDoor는 쓰지 않는다(교수님: 더 좋은 모델·방식을 써도 됨).
- **주제 변경(2026-09-30)**: 옷 입어 보기는 AnyWear라는 기존 프로그램이 있어 접고, **헤어·네일아트·메이크업·타투**로 바꿨다. 옷 관련 코드(착용 변형, 상품 사진 분석, 크롬 확장, 상품 이미지)는 모두 지웠고, 카메라·측정·MediaPipe 추적·WebGL 합성·가이디드 필터는 다시 썼다. 지난 코드는 git 기록에 남아 있다.
- **핵심 한 줄(2026-10-18, 사용자가 "이게 핵심, 꼭 기억"이라 확인)**: 마음에 드는 사진 한 장을 고르면, 그 사진의 **메이크업·헤어(염색)·네일아트·타투만** 따와서 내 모습(웹캠 실시간 또는 내 사진)에 자연스럽게 입혀 보여 주는 가상 뷰티 체험 웹 앱. 얼굴 합성 아님. 못 찾으면 못 찾았다고 말한다.
- **제품 정의(2026-10-18, 사용자 말)**: "얼굴 두 개를 합성하는 게 아니다. 메이크업·헤어·네일·타투만 따와서 (내게) 적용하는 것." 고른 사진에서 그 넷을 인식 못 하면 못 했다고 알려 준다(`photo-style.ts` summary 의 "…은 이 사진에서 찾지 못했어요"). 🔁 사진 속에 내 얼굴(얼굴 바꾸기: 브라우저 점 휘기 + 서버 inswapper)은 제품 기능이 아니므로 `?swap=1` 일 때만 단추가 보이는 시험 도구로 남김. 개선 바퀴는 메이크업·헤어·네일·타투 품질에만 쓴다.
- 조건: MacBook Air M5 16GB, 윈도우 NVIDIA GPU PC 있음(필요 시), 추가 예산 없음, 1인 개발, 결과물은 공개 웹.
- 공개 저장소이므로 저작권 있는 사진·영상은 커밋하지 않는다. 시험 자료는 `web/public/testdata/`(gitignore)에만 둔다.
- 개발일지는 하루가 끝날 때 `docs/devlog/`에 쓴다(예약 작업 "IRIS 개발일지 기록", 매일 22:50 한국 시간).

- 시험 사진의 얼굴이 작으면(얼굴 폭 100px 안팎) 아이라인이 거의 안 보인다(선 두께가 얼굴 폭 비례라 의도된 동작).
