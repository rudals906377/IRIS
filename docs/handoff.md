# 작업 인수인계 (다음 세션용)

작성: 2026-09-30(주제 변경 후 갱신). 새 세션이 IRIS **가상 뷰티**를 이어받아 완성하기 위한 문서다.

## 1. 사용자와 약속된 방식

- **모든 대화·진행 안내·문서·커밋 메시지는 한국어**로 쓴다. 영어는 기술 용어에만 쓴다.
- 사용자는 이 분야를 잘 모르며 "알아서 해 달라"고 했다. 결정은 스스로 내리고, 사용자 손이 꼭 필요한 일(맥북에서 직접 써 보기, 설정 한 번 바꾸기)만 짧고 쉽게 요청한다.
- 목표는 "최고의 결과물". 빨리 완성하고 남은 두 달은 완성도를 끌어올린다. AnyDoor는 쓰지 않는다(교수님: 더 좋은 모델·방식을 써도 됨).
- **주제 변경(2026-09-30)**: 옷 입어 보기는 AnyWear라는 기존 프로그램이 있어 접고, **헤어·네일아트·메이크업·타투**로 바꿨다. 옷 관련 코드(착용 변형, 상품 사진 분석, 크롬 확장, 상품 이미지)는 모두 지웠고, 카메라·측정·MediaPipe 추적·WebGL 합성·가이디드 필터는 다시 썼다. 지난 코드는 git 기록에 남아 있다.
- 조건: MacBook Air M5 16GB, 윈도우 NVIDIA GPU PC 있음(필요 시), 추가 예산 없음, 1인 개발, 결과물은 공개 웹.
- 공개 저장소이므로 저작권 있는 사진·영상은 커밋하지 않는다. 시험 자료는 `web/public/testdata/`(gitignore)에만 둔다.
- 개발일지는 하루가 끝날 때 `docs/devlog/`에 쓴다(예약 작업 "IRIS 개발일지 기록", 매일 22:50 한국 시간).

## 2. 지금까지 된 것

| 영역 | 상태 |
|---|---|
| 추적 | MediaPipe 얼굴 점 478개(Face Landmarker), 다중 클래스 분할(R 머리카락, G 몸 피부, B 얼굴 피부, A 사람), 손·자세는 선택. 얼굴 점은 One Euro 필터로 떨림 억제, 놓치면 150ms 유지 후 서서히 사라짐(`face.ts`) |
| 메이크업 | 립(입 안 제외, 광택), 아이섀도(눈동자·흰자 제외, 색조+곱하기), 블러셔(광대 쪽 타원), 아이라이너(꼬리 뺀 선), 눈썹(곱하기). 반 해상도 마스크 → 부위별 가우시안 흐림(얼굴 폭 비례) → 원래 밝기를 살린 색 입히기. 손이 얼굴 앞에 오면 숨김 |
| 헤어 컬러 | 머리카락 확률(가이디드 필터) → 64×64 통계 텍스처 밉맵으로 평균·분산 → 상대 밝기로 목표색 조절, 밝은 결은 채도 낮춤, 경계는 상대 밝기를 1로 눌러 테두리 번쩍임 방지, 옴브레(얼굴 점으로 뿌리·끝 위치) |
| 타투 | 자세 추적(타투를 켤 때만 켬) + 얼굴 턱선 보조점 → 부위 축 → 격자(팔은 원기둥: 화면 오프셋 R·sinθ, 보임 cosθ). 분할 G로 팔 굵기 측정·평활. 피부(G, 가까운 목은 B도)에만 곱하기 잉크. 가로로 긴 도안은 팔 방향으로 회전. 도안은 Path2D 선화 7종 + 사진 올리기(밝은 바탕 자동 제거) |
| 화면 | 아래 탭(룩/립/아이섀도/블러셔/아이라이너/눈썹), 색 견본 + 직접 고르기, 농도·광택 슬라이더, 룩 6종 |
| 측정 | 단계별 처리 시간(얼굴·분할·자세·효과·그리기), 촬영→그리기 지연, 거울 루프백, JSON 내보내기 |
| 배포 | GitHub Actions → Pages. 사용자가 Settings → Pages → Source를 "GitHub Actions"로 바꿔야 첫 배포 성공(아직 미확인) |

## 3. 구조

README의 "구조" 참고. 효과는 `renderer.draw({effects})`에 함수로 넣으면 카메라를 그린 뒤 차례로 그려진다. 새 기능(헤어 컬러·타투·네일)은 `web/src/beauty/`에 효과 하나씩 추가하는 방식으로 붙인다.

## 4. 개발·시험 명령

```bash
cd web && npm ci && npm test && npm run build          # 단위 테스트, 사이트 빌드(dist/)
npx vite preview --port 4173 &                          # 시험 서버
bash tools/harness/fetch-testdata.sh                    # 시험 자료(얼굴 확대 영상 포함)
cd tools/harness && npm install                         # playwright
```

헤드리스 크롬은 GPU가 없어 느리므로 **속도 판단은 하지 말고 모양만** 본다.

## 5. 다음 할 일 (우선순위 순)

1. **네일아트**: 손 점(손가락 끝·마디) → 손톱 사각형 추정(손등이 보일 때만) → 색·무늬
2. 메이크업·헤어·타투 다듬기(타투: 손등·다리 위치, 컬러 잉크, 팔 비틀림)(선명한 원색 염색이 어두운 머리에서 조금 평평해 보임): 입술 윤곽을 조금 넘게 칠하는 "오버립" 옵션, 펄 섀도, 피부 톤 보정(베이스), 얼굴 옆으로 돌렸을 때 먼 쪽 블러셔 약하게
3. 실제 기기(맥북)에서 속도·지연 측정

## 6. 알려진 문제·아이디어

- 시험 사진의 얼굴이 작으면(얼굴 폭 100px 안팎) 아이라인이 거의 안 보인다(선 두께가 얼굴 폭 비례라 의도된 동작).
- 타투는 거울 모드에서 좌우가 바뀌어 보인다(실제 거울과 같음). 레터링도 거울에서는 뒤집혀 보인다.
- 헤어 스타일(길이·모양) 바꾸기는 생성형 AI가 필요해 실시간으로는 어렵다. 사진 한 장 모드로 NVIDIA PC에서 돌리는 방안을 검토.
