# IRIS — 실시간 가상 뷰티

웹캠 속 **지금 움직이는 내 얼굴**에 메이크업을 거울처럼 바로 입혀 보는 웹 서비스입니다.
헤어 컬러·타투·네일아트로 넓혀 가는 중입니다.
미래내일 일경험 「마스크 기반 영상합성 기술 구현」 프로젝트.

- 사이트: https://rudals906377.github.io/IRIS/
- 작업 인수인계: [docs/handoff.md](docs/handoff.md)
- 개발일지: [docs/devlog](docs/devlog/README.md)
- 지난 조사·설계(옷 입어 보기 시절): [docs/realtime-virtual-try-on-plan.md](docs/realtime-virtual-try-on-plan.md)

## 특징

- **모든 처리가 브라우저 안에서**: 카메라 영상은 기기 밖으로 전송하거나 저장하지 않습니다. 서버 비용도 없습니다.
- **마스크 기반 합성**: 얼굴 점 478개(MediaPipe Face Landmarker) → 부위별 영역(입술·눈꺼풀·볼·눈썹·아이라인) → 부드러운 마스크 → 원래 피부의 밝기·주름을 살린 색 입히기.
  - 입을 벌리면 입 안은 칠하지 않고, 손이 얼굴 앞에 오면 그 부분은 화장을 숨깁니다(피부 분할).
  - 아이섀도는 눈동자·흰자로 번지지 않고, 속눈썹 쪽이 진하고 위로 갈수록 옅어집니다. 펄(고개를 움직이면 반짝이는 반짝이)도 고를 수 있습니다.
  - 립은 모양(풀 립·그라데이션·블러), 광택, 입술 라인(윤곽보다 도톰하게 칠하는 오버립)을 고를 수 있습니다.
  - **조명 맞춤 색**: 볼 피부의 평균색으로 조명의 밝기·색온도·채도를 추정해 화장 색을 그 조명에 맞춥니다(어두운 방에서 립만 형광처럼 뜨지 않음). 블러셔·섀도·눈썹은 원래 피부에 색 비율을 곱해 피부 결이 그대로 비칩니다.
  - 눈썹은 눈썹 올은 진하게, 올 사이는 옅게 채우고 꼬리는 가늘게 모읍니다. 얼굴을 옆으로 돌리면 먼 쪽 화장은 옅어집니다.
- **윤곽(쉐딩·하이라이터)**: 광대 아래·턱선·관자놀이·코 옆에 음영, 콧대·광대 위·인중 위·턱 끝·이마에 빛(빛을 받는 곳일수록 더 밝게). 얼굴 피부 위에만 칠합니다.
- **피부 보정(베이스)**: 얼굴 피부에서 이목구비를 뺀 곳의 작은 잡티·결만 줄이고(큰 경계는 유지) 붉은기·얼룩을 고르게, 파운데이션 호수(17~25호 등)로 톤을 맞춥니다.
- **헤어 컬러**: 올의 밝기 '비율'(픽셀/주변, 주변/머리 평균)로 명암을 살려 색을 바꿉니다(어두운 머리 → 블론드·노랑도 결이 유지). 뿌리→끝 그라데이션(옴브레) 지원. 얼굴이 보이면 머리 주변을 따로 잘라 한 번 더 분할해 경계 해상도를 2배로 올리고, 가이디드 필터와 밝기로 올 단위 경계를 다듬습니다.
  - **자체 학습 머리카락 모델(실험)**: 공개 얼굴 데이터의 머리카락 라벨을 큰 모델(ViTMatte·BiRefNet)로 정밀화해 만든 경량 매팅 모델([tools/train/hair](tools/train/hair/README.md))을 브라우저(onnxruntime-web)에서 돌립니다. 설정 → "자체 학습 머리카락 모델 사용". 1차 학습본은 범용 분할과 동급이며, 전체 데이터·GPU 재학습으로 올릴 예정입니다.
- **타투**: 도안 7종(직접 그린 선화) 또는 내 사진을 팔 아래·위, 목 옆, 쇄골 아래에. 팔은 원기둥으로 보고 둘레를 따라 감으며, 굵기는 피부 분할로 잽니다. 피부에만 새겨져 옷·머리카락이 덮으면 가려지고, 피부 결과 명암이 비칩니다. 가로로 긴 레터링은 팔을 따라 세로로 넣습니다.
- **사진 따라하기**: 마음에 드는 사진을 올리면 그 사진의 색과 스타일을 내 얼굴·머리·손톱·팔에 바로 적용합니다.
  - 색은 사진에서 직접 잽니다(얼굴 점 478개로 입술·볼·눈꺼풀·눈썹, 분할로 머리카락, 손 점으로 손톱). 조명 방향과 앞머리 그늘의 영향을 줄이려고 얼굴 피부 밝기 흐름을 수식으로 맞춘 뒤 "그 자리의 예상 피부색" 대비로 비교합니다.
  - 적용한 뒤 내 얼굴을 같은 방법으로 다시 재서 사진과 같은 정도가 될 때까지 색·진하기를 고칩니다(되먹임). 시험 얼굴에 화보 21장을 적용했을 때 입술색 오차 0.002, 블러셔·섀도 색조 오차 약 0.04~0.05.
  - **스타일 AI**(별도 저장소 [rudals906377/AI](https://github.com/rudals906377/AI)의 분류기)가 무늬·모양·기법(블러립, 스모키, 프렌치·자석 네일, 옴브레, 타투 부위·크기 등)을 읽어 함께 적용합니다. 처음 한 번 약 94MB 모델을 내려받으며, 사진은 기기 밖으로 나가지 않습니다. 설정에서 끌 수 있습니다.
- **생성 모드(사진 한 장)**: 실시간으로는 안 되는 헤어 **모양·길이**, 세밀한 **네일아트**, 사진 그대로의 **타투**를 생성형 AI로 그립니다. 웹캠 한 장 + 참고 사진 + 스타일 AI가 읽은 속성을 내 컴퓨터의 생성 서버([tools/genserver](tools/genserver/README.md), SDXL 인페인팅 + IP-Adapter Plus, GPU 메모리가 작으면 SD1.5)로 보내 결과를 전후 비교로 보여 줍니다. 얼굴은 그대로 두고 지정한 영역만 다시 그리며, 생성 뒤 머리색을 참고 사진 색에 맞추는 **색 고정**이 붙어 있습니다. 사진은 인터넷으로 나가지 않습니다(다른 컴퓨터에서 쓰려면 터널, README 참고).
- **손톱 라벨 도구**([label.html](web/label.html)): 손 사진을 열면 손 점으로 손톱 자리를 짐작해 그려 주고, 꼭짓점을 끌어 맞춘 뒤 JSON으로 저장합니다. 손톱 전용 모델([tools/train/nail](tools/train/nail/README.md)) 학습 데이터용입니다.
- **룩과 부위별 조절**: 데일리·코랄·레드 립·스모키·로즈·글램·맨얼굴 룩, 부위별 색(직접 고르기 포함)과 농도.
- **실시간성 측정 내장**: 단계별 처리 시간, 촬영→그리기 지연, 건너뛴 프레임, 1분 단위 추세, 거울 루프백 지연 측정, JSON 내보내기.

## 로드맵

| 순서 | 기능 | 방식 |
|---|---|---|
| 1 | 메이크업(피부 보정·윤곽·립·아이섀도·블러셔·아이라이너·눈썹) | 얼굴 점 → 영역 마스크 → 조명에 맞춘 색 입히기 **(완료, 다듬는 중)** |
| 2 | 헤어 컬러 | 머리카락 분할 + 가이디드 필터(올 단위 경계) → 밝기 살린 염색, 옴브레 **(완료)** |
| 3 | 타투 | 자세·피부 분할 → 도안을 팔(원기둥으로 감기)·목·쇄골에 붙이기 **(완료)** |
| 4 | 네일아트 | 손 점(손가락 끝) → 손톱 영역 추정 + 영상 밝기로 경계 다듬기 → 색·무늬 **(2차, 계속 개선 중)** |
| 5 | 생성 모드 | 헤어 모양·길이, 세밀한 네일아트, 사진 그대로의 타투를 로컬 생성 서버로 **(GPU 실사용 확인, SDXL + 색 고정)** |
| 6 | 자체 모델 | ① 머리카락 매팅(1차 학습본 탑재) ② 손톱 분할(라벨 도구·학습 스크립트 준비, 데이터 수집 중) ③ 헤어 생성 LoRA(예정) |

헤어 **스타일**(길이·모양) 바꾸기는 생성형 AI가 필요해 실시간으로는 어렵습니다. 사진 한 장 모드로 따로 검토합니다.

## 사용법

1. 사이트를 열고 **카메라로 시작**을 누른 뒤 카메라 권한을 허용합니다. 카메라가 없으면 **예시 영상으로 체험**.
2. 얼굴이 화면 가운데 오게 하면 바로 화장이 입혀집니다.
3. 아래 **룩** 탭에서 전체 분위기를 고르고, 립·아이섀도 등 탭에서 부위별 색과 농도를 바꿉니다.

잘 나오는 조건: 밝고 고른 조명, 정면에 가까운 얼굴.

## 지연 측정 방법

| 방법 | 방법 요약 | 정확도 |
|---|---|---|
| 앱 안의 측정 표시 | 상단 **측정** 버튼 → 처리 시간·촬영→그리기 지연(브라우저가 지원할 때) | 소프트웨어 구간만 |
| 거울 루프백 | **설정 → 거울 루프백 측정**. 노트북 화면 앞에 거울을 들면 화면 깜빡임을 카메라가 보고 왕복 지연을 30회 잽니다 | 카메라+화면 구간(자동) |
| 슬로모션 촬영 | 휴대폰 240fps 슬로모션으로 손(또는 플래시)과 노트북 화면을 한 화면에 찍고, 실제 움직임과 화면 반영 사이 프레임 수 × 4.2ms | 전체 구간(가장 신뢰) |

## 개발

```bash
cd web
npm install
npm run dev        # http://localhost:5173 (카메라는 localhost 또는 HTTPS에서만 동작)
npm test           # 단위 테스트(측정·필터·얼굴 영역·삼각형 나누기)
npm run build      # dist/ 생성
```

헤드리스 브라우저 시험 도구: [tools/harness](tools/harness/README.md)

주소 인자(개발·시험용): `?src=sample`(예시 영상으로 바로 시작), `?look=daily|coral|red|smoky|rose|glam|clear`, `?over=-1~1`(입술 라인), `?lstyle=full|gradient|blur`(립 모양), `?pearl=0~1`(섀도 펄), `?hair=<헤어 색 번호>`, `?tattoo=<도안 id>&place=<위치>&tsize=0~1`, `?nail=<번호>&nstyle=...`, `?ref=<사진 주소>&refmode=auto|makeup|hair|nail|tattoo`(참고 사진 적용), `?hud=1`, `?debug=lm,seg`, `?delegate=CPU|GPU`

### 구조

```
web/src/engine/
  engine.ts     전체 흐름(프레임마다 추적 → 효과 → 합성 → 측정)
  source.ts     카메라·동영상 입력, 프레임 콜백
  tracker.ts    MediaPipe 얼굴 점·분할(머리카락/몸 피부/얼굴 피부)·손·자세(선택)
  face.ts       얼굴 점 떨림 줄이기(One Euro 필터), 놓쳤을 때 서서히 사라짐
  renderer.ts   WebGL2 카메라 그리기, 가이디드 필터, 효과 연결
  metrics.ts    지연·처리 시간 측정
  loopback.ts   거울 루프백 지연 측정
web/src/beauty/
  face-regions.ts  얼굴 점 → 메이크업 영역(진하기 값이 있는 삼각형 망), 얼굴 돌림 추정
  makeup.ts        영역 마스크 → 흐림 → 색 입히기(WebGL2)
  hair.ts          헤어 컬러(머리카락 평균 밝기 통계 → 명암 살린 염색)
  tattoo-place.ts  타투 위치(관절점 → 원기둥 격자), 분할로 팔 굵기 재기
  tattoo.ts        타투 합성(피부에만, 곱하기 잉크)
  tattoo-designs.ts 타투 도안(선화)과 사용자 사진 → 도안 변환
  nail-place.ts    손 점 → 손톱 사각형(손등 방향·접힌 손가락 판단)
  nail.ts          네일 합성(둥근 손톱 모양, 광택, 프렌치·그라데이션·글리터·도트)
  palettes.ts      색상표와 룩
  photo-style.ts   참고 사진 분석(색·스타일 뽑기), face-measure.ts 얼굴 색 측정(피부 밝기 흐름 기준)
  style-math.ts    셰이더 색 계산의 역산, style-match.ts 되먹임(사진과 같은 정도로 맞추기)
  style-ai.ts      스타일 AI 분류기 불러오기, style-attributes.ts 속성 → 앱 힌트·영어 설명
  gen-mode.ts      생성 서버(사진 한 장 모드) 호출
tools/genserver/  생성 서버(파이썬: 마스크, Stable Diffusion 인페인팅 + IP-Adapter)
web/src/app/    화면 구성
```

## 배포

`main` 또는 개발 브랜치에 `web/`이 바뀌면 GitHub Actions가 빌드해 GitHub Pages에 올립니다.
처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔야 합니다.
