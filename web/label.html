사진을 열어 주세요

사진

    쓰는 법

    1. 사진 열기로 손 사진을 여러 장 고른다.
    2. 사진마다 손톱 자리에 자동으로 8각형이 그려진다. 꼭짓점을 끌어서 손톱 테두리에 맞춘다. 안쪽을 끌면 통째로 움직인다.
    3. 잘못 잡힌 건 클릭 후 선택 삭제, 빠진 손톱은 손톱 추가.
    4. 이 사진 완료 → 다음 사진. 작업은 브라우저에 자동 저장된다.
    5. 다 끝나면 라벨 저장으로 JSON 파일을 받아 사진 폴더에 함께 둔다.

    단축키

    ←→ 이전·다음 · Enter 완료 · Del 삭제 · A 추가 · 휠 확대

    주의

    손톱판(분홍·흰 부분)만 감싼다. 큐티클은 제외, 끝의 흰 부분은 포함. 안 보이는 손톱은 그리지 않는다.
