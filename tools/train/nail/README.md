# 손톱 전용 모델 만들기

손 점 21개로 손톱 자리를 짐작하는 대신, 손톱 자체를 찾는 작은 분할 모델을 직접 학습한다.
순서: **사진 모으기 → 라벨 달기(웹 도구) → 학습(GPU PC) → 웹 앱에 넣기**.

## 1. 사진 모으기 (목표 300장 이상, 처음엔 100장으로 시작)

- 웹캠과 같은 환경이 가장 좋다: 책상 앞, 손등이 카메라를 향하게, 손가락을 편 것·조금 오므린 것·옆으로 돌린 것.
- 다양하게: 양손, 밝은 곳·어두운 곳, 가까이·멀리, 네일 바른 손·안 바른 손, 다른 사람 손(가족·친구 동의 받고).
- 한 장에 손 하나가 크게(사진 폭의 1/3 이상) 보이게. 1280×720 정도면 충분하다.
- 한 폴더에 모은다(예: `nails/photos/`). 파일 이름이 겹치지 않게.

## 2. 라벨 달기

1. https://rudals906377.github.io/IRIS/label.html 열기 (또는 `web` 폴더에서 `npm run dev` 뒤 http://localhost:5173/label.html)
2. **사진 열기**로 폴더의 사진을 전부 고른다. 사진은 브라우저 안에서만 쓰이고 올라가지 않는다.
3. 사진마다 손톱 자리에 8각형이 자동으로 그려진다. 꼭짓점을 끌어 **손톱판 테두리**에 맞춘다.
   - 포함: 손톱판 전체(끝의 흰 부분 포함). 제외: 큐티클·살.
   - 안 보이는 손톱(접힌 손가락, 손바닥 쪽)은 삭제. 빠진 손톱은 **손톱 추가**.
4. **이 사진 완료**(Enter) → 다음 사진. 진행 상황은 브라우저에 자동 저장되니 나눠서 해도 된다.
5. 끝나면 **라벨 저장** → `nail-labels.json`을 사진 폴더 옆에 둔다.

하루 1~2시간이면 100~150장. 처음 100장으로 한 번 학습해 보고, 결과를 보며 더 모은다.

## 3. 학습 (GPU PC)

```bat
cd IRIS\tools\train\nail
..\..\genserver\venv\Scripts\activate      (생성 서버 가상환경을 그대로 쓴다. torch 설치돼 있음)
pip install onnx onnxscript onnxruntime
python train.py --images C:\경로\nails\photos --labels C:\경로\nails\nail-labels.json --out out --epochs 40
```

- 화면에 매 회 `검증 IoU`가 찍힌다(1에 가까울수록 좋음). 0.7 넘으면 쓸 만하고, 0.8 넘으면 손 점 방식보다 확실히 낫다.
- `out/samples/`에 사진 · 정답 · 예측 그림이 저장되니 눈으로 확인한다.
- 확인: `python predict.py --onnx out\nail-seg.onnx --image 아무손사진.jpg --out pred.png`
- 결과 파일 `out/nail-seg.onnx`(약 2MB)를 보내 주면 웹 앱에 연결한다(onnxruntime-web으로 브라우저에서 실시간 실행).

## 4. 웹 앱에 넣기 (다음 단계, 코드 작업)

`web/src/beauty/nail-place.ts`의 손 점 기반 사각형을 "모델 마스크 ∩ 손 점 주변"으로 바꾼다.
모델은 손 점으로 자른 256×256 영역에 돌리고(손마다 1회, 약 2~4ms GPU), 마스크 경계를 네일 셰이더의 모양으로 쓴다.
